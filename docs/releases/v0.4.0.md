# Mech Library 0.4.0

First public release. Mech Library is a self-hosted unit database and force builder for
BattleTech Alpha Strike, fed from the Master Unit List.

## Highlights

- **New MUL.** `mul:sync` reads the relaunched Master Unit List
  (masterunitlist.battletech.com) and replaces the old QuickList scraper, which stopped working
  when MUL moved. It keeps the ten-second delay from MUL's `robots.txt`, caches every parsed
  unit page and continues where it stopped after an interruption.
- **All unit types for force building:** BattleMechs, Battle Armor, combat vehicles,
  aerospace fighters, ProtoMechs and small craft.
- **Formation rules aligned with Alpha Strike: Commander's Edition**, including lance
  variants. The formation type dropdown is grouped by family.
- **Print view and PDF** with Alpha Strike style unit cards, heat scale and crit boxes.
- **Logins:** local accounts, Discord (servers as groups) and Mattermost (channels as groups).
  Armies can be limited to a group, so one instance can serve several gaming groups.
- **Docker Compose setup** with the app and MySQL. Migrations run on every start.
- **`bin/console app:doctor`** checks PHP, configuration, database, migrations, login setup and
  directory permissions and says what to fix.

## Smaller changes

- Era multi-select; an intro year filter overrides the era.
- Column toggle menu and highlighting of the sorted column in the unit table.
- Duplicate units allowed in a formation.
- `mul:images` adopts image files that are already on disk instead of downloading them again.
- `mul:sync` reconnects to MySQL when the connection drops during a long run.
- Migrations run through Perpl (`vendor/bin/perpl migration:migrate`).
- Unit cards show the new MUL id.

## Upgrading from 0.3

Run `vendor/bin/perpl migration:migrate`, then `bin/console mul:sync` with the types you need.
The old QuickList cache is not reused; the first sync against the new MUL takes about a day.
Copy the new keys from `.env.example` (login provider, MUL settings) and run
`bin/console app:doctor`.
